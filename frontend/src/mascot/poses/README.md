# Mascot poses

Drop `.vroidpose` files here; the mascot uses each one as an idle pose (she eases into it, holds it a few seconds, and eases out). No code changes needed.

How to make one in VRoid Studio: open a model → **Photo Booth → Poses & Animations → Posing** → pick a preset or pose her yourself → **Save current pose** ([VRoid help](https://vroid.pixiv.help/hc/en-us/articles/13040108436761-How-to-Save-and-Load-Poses)).

- The head is left to the app, so she keeps looking at you; every other bone comes from the file.
- Poses only rotate bones; a pose that needs the hips lowered (sitting, crouching) won't look right while she stands.
- A pose made on one VRoid model works on the others (same bone names).
- Your own poses are yours. Before shipping VRoid's preset poses publicly, check VRoid Studio's terms.
