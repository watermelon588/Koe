# Existing typefaces, served locally

Geist and Geist Mono are the application's existing font families. Local copies remove third-party font requests and keep all three homepage designs consistent.

Downloaded 2026-10-16 from Google Fonts. The files are TrueType:

- `geist-1.ttf`: Geist 300
- `geist-2.ttf`: Geist 400
- `geist-3.ttf`: Geist 500
- `geist-4.ttf`: Geist 600
- `geist-5.ttf`: Geist Mono 300
- `geist-6.ttf`: Geist Mono 400

Source stylesheet: https://fonts.googleapis.com/css2?family=Geist:wght@300;400;500;600&family=Geist+Mono:wght@300;400&display=swap

Both typefaces use the SIL Open Font License 1.1; see the accompanying OFL files and https://github.com/google/fonts/tree/main/ofl/geist and https://github.com/google/fonts/tree/main/ofl/geistmono.
