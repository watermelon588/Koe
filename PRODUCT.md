# Koe

## Platform
Web app and installable PWA, React/TypeScript with FastAPI. One owner and their own accounts; public multi-user signup is outside current scope.

## Job
A developer founder talks or types to manage GitHub work, Google Calendar meetings, Notion records and Sheets hours. Human approval protects writes with consequences. The new Notion workspace provides real connection diagnostics, records and previews alongside the conversational channels.

## Constraints and authority
Budget is zero. Secrets stay backend-only. Preserve the existing mascot, dark/light themes, CSS tokens and voice behavior. The user delegated workspace structure and implementation choices in this request. Calendar owns actual bookings; Notion stores documentation and tasks. No new branding or visual-world replacement is requested. Operational truth and accessible, responsive controls take priority over decoration.

## Open work
Owner provider sign-in is planned separately in docs/AUTH_FLOW.md. Current app uses a development access token. More model credentials are optional and are not assumed available.
