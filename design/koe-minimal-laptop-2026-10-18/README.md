# Koe — minimal laptop mockups

Two matching 4:3 studio images, created 18 October 2026 with the built-in image generator.

- `01-koe-logo.png`: pale mint screen with only the Japanese 声 mark and the name Koe.
- `02-kami-face.png`: the same composition with only Kami’s portrait on screen.

Both use a silver laptop, mint studio backdrop and matching fluted platform, based on the supplied Neuron composition reference. No navigation, application controls, captions or extra props. The second image was generated as an edit of the first to maintain framing and lighting. Native PNGs are preserved without post-processing. Full prompts and references are in `prompts.json`.

Open `index.html` for both originals. Production application code is unchanged.
